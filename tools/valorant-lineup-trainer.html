About Valorant Lineups

Lineup mastery is essential for controller and initiator players. Consistent utility placement can win rounds through post-plant lineups, area denial, and information gathering.

Key Agents for Lineups

  • Sova: Recon dart lineups for info, shock dart post-plants
  • Viper: Molly lineups for post-plant, smoke one-ways

Practice Tips

  • Crosshair Placement: Use environment markers for precise alignment
  • Map Knowledge: Learn 2-3 essential lineups per map before expanding
